# 🎃 Halloween Visitor Analytics Dashboard

## 📊 Project Overview

This project is an interactive **Halloween Visitor Analytics Dashboard** created using **Tableau**.

The dashboard analyzes visitor trends across different years and provides insights into visitor strength, year-wise variation, and future event forecasting.

## 🎯 Objectives

- Analyze year-wise Halloween visitor trends
- Compare visitor numbers across different years
- Identify yearly variations in visitor strength
- Forecast future visitor trends
- Identify the highest visitor year
- Present insights through interactive Tableau visualizations

## 🛠️ Tools & Technologies

- Tableau Public
- Data Visualization
- Dashboard Design
- Forecasting
- Data Analysis

## 📈 Dashboard Visualizations

The dashboard includes:

- **Year-wise Visitor Trend**
- **Forecasting Future Events**
- **Year-by-Year Variation**
- **Visitor Strength**
- **Visitor Strength KPI**
- **Highest Year KPI**

## 🔍 Key Insights

- Visitor numbers vary across different years.
- The dashboard helps identify years with higher and lower visitor strength.
- Forecasting is used to analyze possible future visitor trends.
- KPI cards provide quick information about total visitors and the highest visitor year.

## 🎨 Dashboard Design

The dashboard uses a Halloween-themed background and visual design to make the analysis more engaging and easy to understand.
